BET INTELLIGENCE AFL — Player Intelligence Trial 0.1

Independent disposal projections first. Sportsbet prices second. This trial is designed to test whether BET INTELLIGENCE can add information rather than reorganise bookmaker opinions.

1. The Odds API + AFL game

The Sportsbet response is used only to identify players with disposal markets. Prices are stored but are not shown to the model or ranking process until you freeze the independent projections.

2. Independent AFL history

Required CSV columns: player, team, date, disposals. Recommended: tog, opponent, venue. Dates should be YYYY-MM-DD. TOG should be a percentage such as 82.5.

3. Price-blind model controls

Baseline model: exponentially weighted disposal rate per TOG, shrunk toward the match-player population, with shrunk predictive variance. It intentionally starts simpler than the final model so we can measure whether added complexity genuinely helps.
